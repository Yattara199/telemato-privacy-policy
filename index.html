Politique de confidentialité — Telemato

Dernière mise à jour : 2 octobre 2026

Telemato est un lecteur multimédia. L’application ne fournit pas d’abonnement IPTV et ne distribue pas les chaînes. Vous ajoutez vos propres listes, comptes et sources de programmes.

Données utilisées par l’application

Telemato conserve sur votre appareil les préférences, favoris, éléments de l’historique, listes et réglages que vous choisissez d’enregistrer. Les comptes Xtream Codes sont conservés dans le stockage sécurisé du système lorsqu’il est disponible. Les autres réglages sont conservés dans l’espace privé de l’application. Les enregistrements Android sont écrits dans le dossier privé de Telemato.

Telemato n’intègre actuellement ni publicité, ni SDK d’analyse d’audience, ni service de compte utilisateur exploité par l’éditeur.

Connexions aux fournisseurs et aux sources

Lorsque vous utilisez une URL M3U, un compte Xtream Codes, une source EPG ou un flux, l’application se connecte directement aux adresses correspondantes. Les fournisseurs concernés peuvent recevoir les informations nécessaires à la requête, notamment l’adresse IP de votre connexion, l’URL demandée, les identifiants que vous leur avez fournis et les chaînes ou programmes demandés. Leurs pratiques de conservation et d’utilisation relèvent de leurs propres politiques.

Par défaut, le guide des programmes peut être téléchargé depuis la source EPG Telemato. Vous pouvez définir une autre source EPG. Les logos et images associés aux listes peuvent également être chargés depuis les adresses indiquées dans ces listes.

Les connexions HTTPS utilisent le chiffrement TLS. Une adresse HTTP ne chiffre pas les données transmises. N’activez pas le contournement de validation des certificats TLS pour un usage normal.

Conservation et suppression

Vos comptes fournisseur peuvent être supprimés depuis l’application. Les favoris et l’historique peuvent être effacés depuis leurs écrans respectifs. La désinstallation de Telemato supprime les données conservées dans son espace privé, y compris les enregistrements Android qui s’y trouvent. Les fournisseurs externes peuvent conserver leurs propres journaux selon leurs politiques.

Partage et vente

L’éditeur ne reçoit pas les identifiants ou les flux par un serveur de Telemato et ne vend pas les données de l’application. Les requêtes sont adressées aux fournisseurs, sources EPG et hôtes d’images que vous utilisez, y compris la source EPG par défaut décrite plus haut.
